# SmartFactoryDSS

SmartFactoryDSS is a portfolio-oriented AI-assisted machine maintenance decision support system. It will help maintenance personnel assess the estimated probability of a machine failure within the next 24 hours; it does not autonomously control equipment or make critical operational decisions.

The application will use ASP.NET Core MVC and SQL Server for operational data, with a separate FastAPI service for inference from a trained scikit-learn model.

## Dataset notice

This dataset is synthetically generated for demonstration and educational purposes and does not represent data from a real manufacturing facility.

Detailed setup, architecture, metrics, and usage documentation will be added as the project phases are completed.
